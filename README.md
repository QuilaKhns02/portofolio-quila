## 🚀 Cara Menjalankan Secara Lokal

### Menggunakan Vite Dev Server (Rekomendasi)
Server dev Vite saat ini sudah berjalan pada:
```bash
http://localhost:5173/
```

Untuk menjalankan kembali di lain waktu:
```bash
npm run dev
```

### Build Produksi
```bash
npm run build
npm run preview
```

Website juga dapat dibuka langsung dengan membuka file `index.html` pada browser modern apa pun.
